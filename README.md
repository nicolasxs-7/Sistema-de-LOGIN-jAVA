# Sistema de Login em Java 🔐

Projeto de autenticação via consola desenvolvido em Java, aplicando laços de repetição, estruturas condicionais e captura de dados.

---

## 🚀 Funcionalidades

- *Validação de Credenciais*: Confere utilizador e palavra-passe definidos no sistema.
- *Laço de Repetição*: Mantém o pedido de login ativo até que o acesso seja concedido.
- *Encerramento de Recursos*: Fecho do leitor Scanner após a utilização.

---

## 🛠️ Tecnologias Utilizadas

- *Linguagem*: Java
- *Ambiente*: Visual Studio Code
- *Controlo de Versões*: Git / GitHub
